# MediaCrawler 数据库表结构文档

> 更新日期：2026-03-19
> 数据库：PostgreSQL 15 | 连接：localhost:5444/bettafish
> ORM 定义：`database/models.py`

## 总览

共 **21 张表**，覆盖 7 个平台，每个平台包含：内容表、评论表、创作者表（快手无创作者表）。

| 平台 | 内容表 | 评论表 | 创作者表 | 其他表 |
|------|--------|--------|---------|--------|
| B站 | bilibili_video | bilibili_video_comment | bilibili_up_info | bilibili_contact_info, bilibili_up_dynamic |
| 抖音 | douyin_aweme | douyin_aweme_comment | dy_creator | - |
| 快手 | kuaishou_video | kuaishou_video_comment | - | - |
| 微博 | weibo_note | weibo_note_comment | weibo_creator | - |
| 小红书 | xhs_note | xhs_note_comment | xhs_creator | - |
| 贴吧 | tieba_note | tieba_comment | tieba_creator | - |
| 知乎 | zhihu_content | zhihu_comment | zhihu_creator | - |

### 字段类型约定

| 约定 | 说明 |
|------|------|
| 时间戳 | `BigInteger`，Unix epoch 毫秒 |
| ID 字段 | `BigInteger`（数值型 ID）或 `String(255)`（字符串型 ID） |
| 计数字段 | 多数为 `Text` 类型存储（如 `liked_count`、`fans`），部分为 `Integer` |
| `add_ts` | 记录首次入库时间（epoch 毫秒） |
| `last_modify_ts` | 记录最后更新时间（epoch 毫秒） |
| `source_keyword` | 搜索模式下记录来源关键词 |
